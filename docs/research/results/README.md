# 調査結果の保存場所

ここは **AI担当者が作成する調査報告** のためのディレクトリです。現在、調査結果はまだありません。

- 各担当は `docs/research/prompts/` の指定ファイルにある出力先を**1つだけ**作成してください。
- 同時作業中に他の担当ファイルを書き換えないでください。
- 各担当の調査内容は、根拠が確認できた段階で別ブランチ・別PRで提出してください。
- 調査結果をマージしてから `SYNTHESIS.md` の統合担当を実行してください。
- 統合担当の成果物もPRでレビューしてください。

テンプレート：[`REPORT_TEMPLATE.md`](../REPORT_TEMPLATE.md)
